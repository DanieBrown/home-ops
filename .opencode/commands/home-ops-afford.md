---
description: Estimate conservative home affordability and optionally update the Home-Ops profile
---

Use home-ops afford mode to run the affordability wizard, calculate a conservative purchase-price range, and ask before updating buyer-layer files.

Examples:
- `/home-ops afford`
- `/home-ops afford refresh`

Additional context:
$ARGUMENTS

Load the home-ops skill:
```
skill({ name: "home-ops" })
```
